ArrTags

Sonarr connection

The absolute base URL without an API path, for example http://sonarr:8989.
Sent to Sonarr as the X-Api-Key header. Never logged or surfaced outside Jellyfin's administrator configuration API.

Radarr connection

The absolute base URL without an API path, for example http://radarr:7878.
Sent to Radarr as the X-Api-Key header. Never logged or surfaced outside Jellyfin's administrator configuration API.

Inbound webhook

Required in the X-ArrTags-Webhook-Secret header on the anonymous Sonarr/Radarr webhook endpoints. Never logged or surfaced outside Jellyfin's administrator configuration API.

Badge scope

Choose which Jellyfin libraries are eligible for badges. No selection means no library restriction.

Renderer selectors

Enable or disable each badge selector, edit its bounded display template, and optionally list allowed values. A template contains at most one {value} placeholder. Enter allowed values as comma-separated text; an empty list means no restriction. At most 32 values per selector, each at most 64 characters, unique ignoring case.

Renderer palette

Optional RRGGBB overrides. Leave a value empty to keep the default color. Each text/background pair must reach at least 4.5:1 contrast.

Operational limits

Bounds validated when the configuration loads. An out-of-range value is rejected and the last valid configuration stays active.

Logging

How much ArrTags writes to the Jellyfin server log. This bounds ArrTags only; it never changes the Jellyfin host log level, applies without a restart, and never changes rendered posters.
